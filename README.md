# LaboratorioApp

Aplicación de escritorio en C# para la gestión de préstamos e inventario de equipos de laboratorio.

## Novedades v1.0.0
- **Interfaz Gráfica:** Implementada la GUI principal en Windows Forms (Form1.cs).
- **Gestión de Inventario:** Control de disponibilidad, límites de préstamos y validaciones en LaboratorioService.cs.

## Problemas Conocidos
- **Duplicidad de botones:** Se detectó duplicidad de eventos/controles en Form1.cs pendiente de corrección.
